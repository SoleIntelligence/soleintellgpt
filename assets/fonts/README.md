# Fonts

Barlow Condensed (700 and 800) and Manrope (400, 600, 700), downloaded from Google Fonts and self-hosted to avoid a runtime font dependency. Both families are distributed under the SIL Open Font License. License texts are included beside the font files.

Runtime fonts are WOFF2 subsets covering Latin text, punctuation, and directional arrows. Original TTF files are retained alongside their SIL Open Font Licenses.
