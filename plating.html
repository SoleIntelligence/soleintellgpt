You can't fix what you don't
understand. Start with the deforming forces.

The plate isn't the construct — the force it neutralizes is. Four modes, one job each. Match the failure pattern to the mechanical answer.

01 / Mode
Neutralization
↻ Rotational forces
Lag screw provides compression. Plate protects it from torsion. The plate isn't loaded axially — it's resisting twist.
02 / Mode
Cerclage Compression
⊕ Compression (wiring)
The current term. We don't call it "tension band" anymore — language has moved on, the biomechanics haven't.
03 / Mode
Antiglide
⇄ Shear control
Plate sits as a mechanical block. Stops the fragment from migrating along an oblique fracture line under shear load.
04 / Mode
Buttress
↓ Axial load control
For fractures unstable in compression — not rotation. Construct is load-sharing. Prevents axial collapse at the joint surface.
